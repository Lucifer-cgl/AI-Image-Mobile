# v0.1.0-alpha

首个可安装预览版，仅支持 ARM64 Android 9 及以上设备。

## 已验证

- Redmi 21091116C / Android 13 / Mali-G68 MC4。
- 中文提示词通过 Qwen2.5 1.5B Q4 在本机 CPU 规划。
- LCM DreamShaper Q4 通过 Vulkan GPU 生成图片。
- TAESD 本地解码、历史记录、删除和保存到相册。
- 划掉最近任务后取消推理并释放模型内存。

## 安装

1. 下载并安装 `AI-Image-Mobile-v0.1.0-alpha.apk`。
2. 打开“模型管理”，依次下载三个必需模型包。
3. 客户端优先尝试国内镜像，失败后自动切换到第二镜像和 GitHub 官方地址。
4. 主图片模型会自动下载两个分片、校验、合并；不要手工拼接。

## 已知限制

- 这是 Debug 签名的 Alpha 安装包，不是商店正式版。
- 256×256 四步真机生图约 75 秒，质量仍需继续优化。
- 当前原生运行时面向 ARMv8.2、FP16 和 dot-product 指令设备。
