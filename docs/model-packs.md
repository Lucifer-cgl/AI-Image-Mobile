# 模型包规范

模型清单位于 `model-packs/catalog.json`。每个包包含：

- 唯一ID、版本和用途。
- 文件名、字节数和SHA-256。
- 上游项目、模型许可证和许可证链接。
- 最低RAM、推荐后端和是否必需。
- 按顺序排列的下载源。

下载顺序默认是：

1. 国内镜像一代理的项目 GitHub Release 附件。
2. 国内镜像二代理的项目 GitHub Release 附件。
3. 项目 GitHub Release 官方地址。

任何地址下载得到的文件都必须满足相同的大小和SHA-256。校验失败时删除 `.partial`，自动切换下一个来源，不能把损坏文件交给推理引擎。

超过 GitHub 单附件 2 GiB 限制的模型使用 `parts` 数组发布。客户端下载时支持每片断点续传和 SHA-256 校验；全部分片完成后按顺序合并，并使用目标文件的 SHA-256 做第二次完整校验。用户不需要手工合并。

仓库不重新分发许可证不允许打包的权重。发布模型附件前必须记录上游来源与许可证。
